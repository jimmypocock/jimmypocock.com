### Vocal Technique Translator

Live: vocaltechniquetranslator.com | GitHub: github.com/jimmypocock/vocaltechniquetranslator.com

Built to solve a real problem I encountered learning to sing - transforming song lyrics into phonetic representations that maintain proper vocal technique. This NextJS/TypeScript application helps singers achieve better resonance and reduce vocal strain through systematic phonetic modifications.

TECHNICAL HIGHLIGHTS:
Serverless architecture on AWS using CloudFormation (7 independent stacks for modularity). CloudFront CDN with 99.9% uptime, sub-second response times. Comprehensive feedback system with S3/Lambda/API Gateway for crowdsourced improvements. E2E testing with Playwright ensuring transformation accuracy. AI-ready architecture for future ML integration.

WHY IT MATTERS:
Addresses a niche but passionate market (vocal students/coaches) with no existing digital solution. Built with the same production-grade standards as RoverPass - proper monitoring, security (WAF), and scalability. The feedback loop design shows product thinking beyond just code.

### SongSnips - YouTube Loop Tool

Live: songsnips.com | GitHub: github.com/jimmypocock/songsnips.com

Musicians need to loop difficult passages. Language learners need to repeat phrases. I built SongSnips to do one thing perfectly - loop any section of a YouTube video with precision and zero friction.

TECHNICAL EXCELLENCE:
Next.js 13+ with TypeScript for type-safe development. YouTube IFrame API integration with custom React hooks. Client-side only - no backend, no accounts, no tracking. Comprehensive test coverage (Vitest unit tests + Cypress E2E). Keyboard shortcuts for power users (spacebar play/pause, arrow key navigation).

PRODUCT FOCUS:
Intentionally simple. No feature creep. Load video → Set loop points → Practice. The saved loops feature uses localStorage for privacy. Share loops via URL parameters. Built for musicians by a musician who understands the frustration of YouTube's lack of native looping.

### AWS Cost Delta Monitor

GitHub: github.com/jimmypocock/AWSDeltaCostUsage

"It only takes one oopsie to ruin your month." Built this after a close call with runaway AWS Comprehend costs. Sends timezone-aware cost reports 4x daily and immediately alerts on anomalies - especially for expensive AI services.

ENGINEERING DECISIONS:
Python Lambda with SAM deployment for infrastructure as code. Intelligent anomaly detection with dual thresholds (% AND $ must exceed). AI service multiplier (0.5x) for extra sensitivity on Bedrock, Comprehend, etc. Cost-conscious design: Uses daily granularity to keep monitoring costs at $5-12/month. Global timezone support with automatic DST handling.

REAL IMPACT:
Catches cost spikes before they become disasters. Special focus on AI services because they can burn through budgets in hours, not days. Built with hard limits and conservative pagination to prevent the monitoring tool from becoming the problem.
